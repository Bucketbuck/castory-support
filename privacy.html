隐私政策

生效日期：2026年11月2日。本政策适用于由 Zhen Ning 提供的 Castory iOS/iPadOS App。

1. 本机记录

出钓日期、地点、经纬度、鱼种、数量、鱼饵、尺寸、重量、天气、浪况、笔记及所选照片、视频和截图保存在设备的 App 存储中。Castory 不要求注册、不提供账号同步，平台 AI 仅处理你主动同意发送的素材预览和聚合统计，不提供记录云同步，也不内置广告、行为跟踪或分析 SDK。设备系统备份可能保存 App 数据，受你的 Apple 备份设置控制。

2. 照片、视频和位置

App 只读取你通过系统素材选择器选择的照片和视频，并尝试读取原文件的拍摄时间和 GPS。文件指纹、相册来源标识及预览画面用于本机查重和分组；画面相似不代表同一条鱼。视频不做全片扫描，只生成选定时刻的截图，允许调整截图时刻。保存后的原视频和截图保留在本机，视频可能仍含原始元数据。不会后台访问整个相册，也不会使用手机当前定位冒充拍摄位置。导入后的预览 JPEG 会去除原始元数据，读取出的时间和坐标单独作为本机记录保存。照片中的可见内容仍可能包含个人信息，请注意选择。

3. 主动联网功能

  • 天气匹配：仅当你点击匹配时，将该条记录的时间、经纬度发送到 Open-Meteo，以查询天气和可能可用的海浪模型数据。服务商也会收到网络连接必要的 IP 等技术数据。Open-Meteo 表示其技术日志可能包含坐标，日志保留90天。服务条款及保留方式见 Open-Meteo 条款和隐私说明。
  • 可选 AI 识鱼：素材分组在本机完成，不上传素材。在线识别首次使用时授权，之后由你主动发起。未保存自己的 Key 时，通过部署在 Google Cloud 的 Castory 平台 AI 转发到 DeepSeek；已配置自己的 API 时，直接发送到你设置的 HTTPS 服务地址和模型。确认分组并点击识别后，会将素材的照片预览、视频选定截图去除元数据后发送到所选 AI 服务，用于评估鱼种、尺寸、重量；内容分析还会发送你填写的鱼组标签以定位目标个体，请勿在标签中填写私人信息；不发送视频或历史素材。分组和估计均需人工核对，无依据的尺寸重量留空。不会附加记录中的 GPS、日期、笔记或姓名。图片中的可见文字、人脸及背景仍会发送。
  • 可选 AI 总结：同意后发送当前筛选结果中最多最近200场的时段、天气、鱼饵和浪况聚合统计（每维最多20组），包括出钓次数、渔获数和时长。不发送照片、坐标、钓点名称、精确日期或笔记。鱼饵标签是你填写的文字，请勿放入私人信息。
  • 自带 Key 模式通过 HTTPS 直接请求你设置的 Chat Completions 兼容服务，你的 Key 仅用于向该服务认证；其数据处理遵循你所选服务商的隐私政策和 API 条款；平台模式通过 HTTPS 经过 Google Cloud 上的 Castory 后端再请求 DeepSeek，运营 Key 仅保存在服务端 Secret Manager。平台不保存图片、提示词或 AI 结果。为了验证合法安装和限制用量，平台保存 App Attest 安装公钥、验证计数器、用量计数及短期防重复请求标识，不与姓名或账号关联。Google Cloud 可能保留网络请求所需的 IP、时间、状态等技术日志，受其服务配置和隐私政策约束；日志不包含图片、提示词或响应正文。DeepSeek 可将请求与其 API 账户关联，并按其政策处理、保留请求和网络技术信息。详情见 DeepSeek 隐私政策。Castory 不控制服务商的数据保留，也不保证第三方请求不会被保留。DeepSeek 的账户服务政策包含服务改进和模型训练等可能用途；请同时查看你自己的 API 账户条款及数据选项。对 API 服务的具体处理，另见 DeepSeek 开放平台条款。
  • 打开 Apple 地图或支持网页时，相关服务可根据自己的政策处理网络和地图请求。

4. API Key

用户的 Key 保存在设备钥匙串中，仅在设备解锁时可读，使用 ThisDeviceOnly 属性，不通过 iCloud 钥匙串同步。Key 不写入安装包、本机记录数据库、JSON 导出或 Castory 服务器。不在聊天、支持反馈或公开截图中发送 Key。可在“设置”点击“恢复使用 Castory”；卸载 App 不一定删除钥匙串项目，也可在对应服务商平台撤销 Key。

5. 控制与删除

可以不启用 AI、不匹配天气，仍可记录和进行本机统计。可在记录详情中删除记录及关联照片、视频和截图。JSON 导出由你主动保存或分享，包含坐标但不含照片、视频或截图；请自行控制导出文件和接收人。删除 App 通常会删除其本机数据库，但系统备份和第三方服务已收到的数据需分别管理。服务商数据删除应联系相应服务商。

6. 费用、儿童和安全

Castory 当前不包含内购或订阅。自带 Key 模式的 API 费用由你的账户承担；平台模式由 Castory 承担 API 费用并设有用量限制。App 不针对儿童提供服务，也不主动收集年龄信息。网络使用系统 HTTPS；无法保证任何设备或第三方网络服务绝对安全。AI 鉴定可能出错；天气和浪况不是航行或安全判断依据。

7. 支持和政策更新

隐私问题可通过 支持页面 联系。GitHub 问题默认公开，请勿提交私人数据。支持网站由 GitHub Pages 托管，其技术日志受 GitHub 隐私政策管理。本页面会随数据处理方式变化更新日期。

Privacy Policy

Effective November 2, 2026. Castory is provided by Zhen Ning.

Fishing records, selected photos, videos and extracted frames are stored locally. File fingerprints, picker identifiers and preview similarity support local duplicate checks; similarity does not prove fish identity. Videos are not scanned end to end. Original saved videos may retain metadata. No Castory account, advertising, tracking SDK, or fishing-record cloud sync is used. The optional platform AI gateway runs on Google Cloud. OS backups may include app data. The system photo picker provides only your selected photos and videos; photo time and GPS are read when available, with no background location access.

Weather lookup is optional and sends the record's time and coordinates to Open-Meteo. Optional AI requires authorization before first use and is then initiated by you. Without a personal API key, requests are forwarded through Castory on Google Cloud to DeepSeek. With a personal key, requests go directly to the HTTPS Chat Completions-compatible endpoint and model you configure. Its privacy policy and API terms apply. Grouping runs locally using capture time, short-video intervals and conservative image matching without uploading media. Optional fish assessment sends re-encoded photos and selected video frames without attached metadata, never original videos or historical media. Assessment also sends the fish-group label to identify the target fish; avoid private information in labels. Group identity and size or weight estimates need user review; visible personal information can remain. AI summaries send aggregated time, bait, weather, wave, catch and fishing-duration statistics for up to 200 recent trips, not photos, coordinates, location names or notes. Avoid private information in bait labels.

Personal-key requests go directly over HTTPS to your selected provider; platform requests go through Castory on Google Cloud. The gateway does not persist images, prompts or AI responses. It retains installation public keys, verification counters, usage counts and temporary duplicate-request identifiers for authentication and rate limits, without names or accounts. Google Cloud may retain technical request logs such as IP, time and status, without request/response bodies. Providers receive network metadata and may retain requests under their policies; DeepSeek can associate requests with your API account. Castory does not control provider retention. See the provider policy links above.

Your API key is stored in the device Keychain using WhenUnlockedThisDeviceOnly, not in the app bundle, database, exports or a Castory server. Delete it in Settings or revoke it at the provider; uninstalling may not clear Keychain items. Personal-key usage is billed by your selected API provider. Castory covers platform API usage within its limits; the operator key stays in server-side Secret Manager. Castory currently has no in-app purchases or subscriptions.

You can use local logging and statistics without AI. Delete individual records in the app. Exports include coordinates but not photos, videos or extracted frames and are controlled by you; they are not a complete backup. Manage OS backups and provider-held data separately. Contact support through the linked GitHub issue form without disclosing private data; issues are public. This support website is hosted by GitHub Pages and subject to its hosting privacy practices.
