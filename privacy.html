隐私政策

生效日期：2026年10月25日。本政策适用于由 Zhen Ning 提供的 Castory iOS/iPadOS App。

1. 本机记录

出钓日期、地点、经纬度、鱼种、数量、鱼饵、尺寸、重量、天气、浪况、笔记及所选照片保存在设备的 App 存储中。Castory 不要求注册、不提供账号同步，不运行自有记录收集服务器，也不内置广告、行为跟踪或分析 SDK。设备系统备份可能保存 App 数据，受你的 Apple 备份设置控制。

2. 照片和位置

App 只读取你通过系统照片选择器选择的照片，并尝试读取原图中的拍摄时间和 GPS。不会后台访问整个相册，也不会使用手机当前定位冒充拍摄位置。导入后的预览 JPEG 会去除原始元数据，读取出的时间和坐标单独作为本机记录保存。照片中的可见内容仍可能包含个人信息，请注意选择。

3. 主动联网功能

  • 天气匹配：仅当你点击匹配时，将该条记录的时间、经纬度发送到 Open-Meteo，以查询天气和可能可用的海浪模型数据。服务商也会收到网络连接必要的 IP 等技术数据。Open-Meteo 表示其技术日志可能包含坐标，日志保留90天。服务条款及保留方式见 Open-Meteo 条款和隐私说明。
  • 可选 DeepSeek 识鱼：需要你保存自己的 API Key，并在每次发送前同意。会重新编码照片并去除元数据后发送到 DeepSeek；不会附加记录中的 GPS、日期、笔记或姓名。图片中的可见文字、人脸及背景仍会发送。
  • 可选 DeepSeek 总结：同意后发送当前筛选结果中最多最近200场的时段、天气、鱼饵和浪况聚合统计（每维最多20组），包括出钓次数、渔获数和时长。不发送照片、坐标、钓点名称、精确日期或笔记。鱼饵标签是你填写的文字，请勿放入私人信息。
  • AI 请求通过 HTTPS 直接发往 api.deepseek.com，你的 Key 仅用于向该服务认证。DeepSeek 可将请求与其 API 账户关联，并按其政策处理、保留请求和网络技术信息。详情见 DeepSeek 隐私政策。Castory 不控制服务商的数据保留，也不保证第三方请求不会被保留。DeepSeek 的账户服务政策包含服务改进和模型训练等可能用途；请同时查看你自己的 API 账户条款及数据选项。对 API 服务的具体处理，另见 DeepSeek 开放平台条款。
  • 打开 Apple 地图或支持网页时，相关服务可根据自己的政策处理网络和地图请求。

4. API Key

用户的 Key 保存在设备钥匙串中，仅在设备解锁时可读，使用 ThisDeviceOnly 属性，不通过 iCloud 钥匙串同步。Key 不写入安装包、本机记录数据库、JSON 导出或 Castory 服务器。不在聊天、支持反馈或公开截图中发送 Key。可在“设置”点击“删除本机 Key”；卸载 App 不一定删除钥匙串项目，也可在 DeepSeek 平台撤销 Key。

5. 控制与删除

可以不启用 AI、不匹配天气，仍可记录和进行本机统计。可在记录详情中删除记录及关联照片。JSON 导出由你主动保存或分享，包含坐标但不含照片；请自行控制导出文件和接收人。删除 App 通常会删除其本机数据库，但系统备份和第三方服务已收到的数据需分别管理。服务商数据删除应联系相应服务商。

6. 费用、儿童和安全

Castory 当前不包含内购或订阅。DeepSeek API 费用由你的 API 账户承担。App 不针对儿童提供服务，也不主动收集年龄信息。网络使用系统 HTTPS；无法保证任何设备或第三方网络服务绝对安全。AI 鉴定可能出错；天气和浪况不是航行或安全判断依据。

7. 支持和政策更新

隐私问题可通过 支持页面 联系。GitHub 问题默认公开，请勿提交私人数据。支持网站由 GitHub Pages 托管，其技术日志受 GitHub 隐私政策管理。本页面会随数据处理方式变化更新日期。

Privacy Policy

Effective October 25, 2026. Castory is provided by Zhen Ning.

Fishing records and selected photos are stored locally. No Castory account, advertising, tracking SDK, or developer-operated record collection server is used. OS backups may include app data. The system photo picker provides only your selected image; photo time and GPS are read when available, with no background location access.

Weather lookup is optional and sends the record's time and coordinates to Open-Meteo. Optional AI requires your own DeepSeek API key and explicit consent per request. Fish identification sends a re-encoded image without attached metadata; visible personal information can remain. AI summaries send aggregated time, bait, weather, wave, catch and fishing-duration statistics for up to 200 recent trips, not photos, coordinates, location names or notes. Avoid private information in bait labels.

Requests go directly over HTTPS to the service provider. Providers receive network metadata and may retain requests under their policies; DeepSeek can associate requests with your API account. Castory does not control provider retention. See the provider policy links above.

Your API key is stored in the device Keychain using WhenUnlockedThisDeviceOnly, not in the app bundle, database, exports or a Castory server. Delete it in Settings or revoke it at the provider; uninstalling may not clear Keychain items. API usage is billed by DeepSeek. Castory currently has no in-app purchases or subscriptions.

You can use local logging and statistics without AI. Delete individual records in the app. Exports include coordinates but not photos and are controlled by you; they are not a complete backup. Manage OS backups and provider-held data separately. Contact support through the linked GitHub issue form without disclosing private data; issues are public. This support website is hosted by GitHub Pages and subject to its hosting privacy practices.
