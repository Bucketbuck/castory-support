Castory

记下每一次出钓，发现属于你的钓鱼规律。

Castory 是适用于 iPhone 和 iPad 的钓鱼手账，支持照片时间/GPS 读取、渔获、鱼饵、尺寸、重量、天气和浪况记录，以及每小时渔获统计。

开始使用

  1. 点击“添加”，直接选择一张或多张照片、视频，也可以手动记录。
  2. 鱼种可点选常见或最近使用项；鱼饵通过图标选择，也可自定义。长度与重量可切换公制/英制，钓点和时长可留空。
  3. 有坐标时，可主动匹配 Open-Meteo 天气；模型数据和浪高需自行核对。
  4. “洞察”按时段、鱼饵、天气、浪况比较每小时渔获。

批量整理照片与视频

点击“添加”后选择照片或视频，相册以独立弹层打开，支持拖选、全选与跨相册选择，不设 30 份的选择数量限制。本机先检查重复和已导入素材，并按拍摄时间自动分组；每条鱼以卡片集中显示全部素材，点“编辑”统一填写参数；点击具体素材可移动、拆分或调整视频截图，核对鱼数后再分析。视频可选择时刻截图，不全片扫描。历史素材可关联已有鱼，避免重复计数。分析结果允许修改，尺寸重量无依据可留空；补充笔记，选择或自定义鱼饵，再保存。同次出钓的鱼可共用一条出钓记录，时长只计一次。

地图钓点

默认读取素材自带的拍摄位置；也可搜索地点、在地图上放置或拖动标记。无需填写经纬度。没有地点也能保存，当前定位只在主动点击时使用。

可选 AI

未保存自己的 Key 时使用 Castory 平台 AI，经 Google Cloud 后端调用 DeepSeek；也可在“设置”选择“使用自己的 API”，填写服务地址、模型和 Key，直连兼容 Chat Completions 的服务；识图需使用支持图片输入的模型。分组在本机完成；在线识鱼和总结首次授权后由你主动发起，结果需核对；平台有用量限制，自带 Key 按对应服务商的 API 用量计费。无需 AI 也可完整记录、查看天气和本机统计。Castory 当前没有内购或订阅。

数据保存与备份

记录、照片、视频和选定截图保存在本机。新视频以独立文件保存，未设置文件体积上限；实际导入仍取决于设备可用空间和系统支持的格式。设备系统备份可能包含 App 数据；Castory 不提供账号同步。导出 JSON 包含记录和坐标，不含照片、视频或截图，且当前不支持导回，因此不是完整备份。删除 App 可能丢失本地记录。Key 请在设置中主动删除，卸载不保证清除钥匙串。

常见问题

没有时间/GPS：部分照片或分享图片不含元数据，请手动补填。天气/浪高缺失：检查坐标和日期，内陆或历史日期可能没有对应数据。AI 失败：检查网络和平台额度；自带 Key 时检查 Key 和 API 余额；鱼种可始终手动填写。

联系支持

提交问题或反馈（GitHub）。请说明设备型号、系统版本和操作步骤，不要发布 Key、精确钓点或私人照片。

隐私政策 / Privacy Policy

Castory is a local fishing journal for iPhone and iPad. Core logging and statistics work without an AI key. Optional AI uses Castory on Google Cloud with DeepSeek, or your own compatible API endpoint, model and key. For help, open a support issue without posting secrets or private fishing locations.
