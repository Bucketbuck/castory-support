Castory

记下每一次出钓，发现属于你的钓鱼规律。

Castory 是适用于 iPhone 和 iPad 的钓鱼手账，支持照片时间/GPS 读取、渔获、鱼饵、尺寸、重量、天气和浪况记录，以及每小时渔获统计。

开始使用

  1. 在“总览”或“手账”添加出钓记录，选择照片后确认拍摄时间与地点。
  2. 补填时长、鱼种、数量、鱼饵与尺寸重量。没有渔获也可以保存。
  3. 有坐标时，可主动匹配 Open-Meteo 天气；模型数据和浪高需自行核对。
  4. “洞察”按时段、鱼饵、天气、浪况比较每小时渔获。示例数据仅用于体验。

可选 AI

在“设置”输入自己的 DeepSeek API Key 并安全保存。识鱼和 AI 总结会在你同意后发送数据到 DeepSeek，API 费用由你的 DeepSeek 账户承担。无需 AI 也可完整记录、查看天气和本机统计。Castory 当前没有内购或订阅。

数据保存与备份

记录和照片保存在本机。设备系统备份可能包含 App 数据；Castory 不提供账号同步。导出 JSON 包含记录和坐标，不含照片，且当前不支持导回，因此不是完整备份。删除 App 可能丢失本地记录。Key 请在设置中主动删除，卸载不保证清除钥匙串。

常见问题

没有时间/GPS：部分照片或分享图片不含元数据，请手动补填。天气/浪高缺失：检查坐标和日期，内陆或历史日期可能没有对应数据。AI 失败：检查 Key、网络和 API 余额；鱼种可始终手动填写。

联系支持

提交问题或反馈（GitHub）。请说明设备型号、系统版本和操作步骤，不要发布 Key、精确钓点或私人照片。

隐私政策 / Privacy Policy

Castory is a local fishing journal for iPhone and iPad. Core logging and statistics work without an AI key. Optional DeepSeek requests use your own API account after consent. For help, open a support issue without posting secrets or private fishing locations.
